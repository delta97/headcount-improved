# Manager state of the union

## What this is

The recurring rollup a manager actually reads: what moved, what is stuck, what needs them.
It is an aggregation pipeline with a fixed set of sources, not a writing exercise — the prose
is the last ten percent.

## Sources, in order

1. **Weekly notes pages** for the window (default: since the last update, usually ~2 weeks) —
   the raw record of what happened and what was decided.
2. **Structured meeting notes** (the per-meeting child pages) — decisions and action items,
   already attributed.
3. **The paid-media weekly brief(s)** in the window — channel signals, blockers, and
   cross-cutting themes, pre-digested.
4. **The current open-items rollup** — run `open-items-rollup` first if it is older than the
   window; a state of the union built on a stale rollup understates what is stuck.

## Structure

BLUF, skimmable in fifteen seconds, detail below the fold:

1. **Headline** — one sentence: the single most important thing this period.
2. **Wins** — shipped or decided, three to five bullets, each with its business consequence,
   not its activity ("intake process approved; portfolio council seated" — never "attended
   twelve meetings").
3. **In motion** — the major workstreams (AIP, paid media, and whatever else the window
   touched), one line each: state, next milestone, date.
4. **Stuck / needs you** — the items only the manager can move: decisions awaited,
   escalations, resourcing. Each one names the ask explicitly. This section is the reason the
   document exists; never let it be empty by politeness — empty means "nothing needs you,"
   and that had better be true.
5. **Risks watched** — two or three, each with the trigger that would escalate it.

## Rules

- Every claim traces to a source page; when a number appears (spend, dates, counts), it comes
  from a note, not from memory of a note.
- Wins are the period's, not the year's. Resist re-reporting a prior period's win because it
  is still impressive.
- Write in the owner's exec-comms register: short sentences, no hedging, asks stated as asks.
- End with the window covered ("June 4–18") so the next update knows where to start.
